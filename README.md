# 🎵 MP3 → MP4 Converter

A simple, offline Windows application that turns an MP3 and an image into an MP4 video.

Built with Python, CustomTkinter, TkinterDnD and FFmpeg.

## ✨ Features

- 🖼️ Add an image as the video artwork
- 🎵 Add an MP3 audio file
- 🖱️ Drag and drop files
- ⚡ NVIDIA NVENC hardware encoding
- 🖥️ CPU H.264 encoding
- 🎥 720p, 1080p, 1440p and 4K output
- 🎚️ 128k, 192k, 256k and 320k audio bitrate
- 📊 Real-time conversion progress
- ⏹️ Cancel conversion
- 💾 Remembers your settings
- 📂 Remembers your last output folder
- 🌑 Dark interface
- 🔒 Completely local processing
- 🌐 No internet connection required

## 🚀 Usage

1. Open the application.
2. Choose an image and an MP3, or drag them into the drop area.
3. Select your desired resolution, audio bitrate and encoder.
4. Click **Convert to MP4**.
5. Choose where to save the resulting video.

## ⚡ NVIDIA GPU Encoding

If your NVIDIA GPU supports NVENC, you can select:

`NVIDIA GPU (NVENC)`

for significantly faster video encoding compared with CPU encoding.
